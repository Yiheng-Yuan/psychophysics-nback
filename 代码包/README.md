# 历版代码压缩包

按可核验的本地发行包归档。ZIP 含原程序、Builder 工程（若原包提供）、配置、代码测试及适用的说明。公开版剔除了被试数据、图片、音频、影片和课件。正式实验版需按配置准备刺激素材，独立热身无需素材。原版本清单中的哈希对应原始发行包。

数据包前缀表示实验版本，后面的 Rxx 表示运行编号。例如 V05-R04 使用 V05 的实验版本。各次运行的直达链接见 [逐次测试数据包](../数据包/运行索引.md)。
