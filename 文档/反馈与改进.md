# 被试反馈、运行问题与后续改进

## 可追溯的反馈

| 证据来源 | 记录 | 对应调整 |
|---|---|---|
| 实验组织者补充的被试口述汇总 | 被试普遍表示原先的情绪诱导没有明显主观作用。未取得逐人原话、具体人数或分条件记录 | 筛选高唤醒影片，改用约 120 秒诱导，并加入前后效价和唤醒度自评 |
| 实验组织者转述的被试策略，加上三个附件运行的复算 | 有被试报告主观有印象就按 J、没有印象就按 F。行为数据中，首次出现的普通非匹配答得更快、更准。两类证据不能识别哪些运行采用了该策略或每次用得多频繁 | 保留诱饵，约束词序结构，使用统计特征接近的配对序列，并按试次类型单独查看表现 |
| 实验组织者补充的设计动机及程序说明 | 上下干扰词改为与中央词同色同大，让它们更难被颜色和大小直接筛掉，目的是提高视觉干扰。实际干扰幅度尚未确认 | 区块前显示说明，加入独立 1–3-back 热身 |
| 实验组织者补充的长版反馈 | 有被试因测试耗时和难度逐步增加而感到消极，想尽快结束。对后程作答的影响尚未单独量化 | 每级有无干扰各从两组减为一组，缩短实验，并按版本记录升级规则 |
| 实验组织者补充的先前数据分析 | 在不同诱导顺序中观察到熟悉任务后正确率上升。同一 N 复算见[预测试数据](预测试数据.md) | 正式实验前加入独立 1–3-back 热身，让被试先掌握按键与目标位置 |
| 用户运行时报告影片播完闪退并提供错误日志 | PsychoPy 播放末尾取帧失败，未进入片后自评。阶段日志和回溯可交叉核对 | 最近正常帧与播放计时都进入最后 0.25 秒时，针对特定错误保留末帧到应有结束时间；较早发生的错误继续上报 |

附件包含行为记录、配置和阶段日志。没有找到独立的逐字访谈附件。表中的口述来自实验组织者转述，属于定性反馈。

## 后续改进

1. 先独立核验三段影片的诱导效果。检查播放前后效价变化、正负条件唤醒度差，以及中性片是否低唤醒。记录视频结束至开始作答的时间，因为在无补充诱导的版本中，较高 N 与距诱导更久同时发生。
2. 均衡六种情绪顺序。保留当前的片前自评，用它检查上一组是否留下明显的情绪差异。若观察到残留，再对是否加入组间过渡做独立预测试。
3. 优先比较同一被试、同一 N 的两种干扰条件，报告命中、虚报、校正后的 d′、诱饵和普通非匹配正确率、正确 RT 与完成率。最高 N 对门槛附近的一题变化敏感，应与连续指标一起解读。
4. 按版本复查熟悉度、诱饵和配对难度。下一轮可用统一问题询问是否比较具体位置、如何处理首次出现的词、上下词是否分散了注意，并记录阶段和原话。
5. 在实际采集环境走完三种情绪并核对日志。已有特定种子导致 2-back 词序生成失败的记录，影片修复没有涉及序列生成器。后续需量化失败频率并测试恢复方案。

## V06 正式运行后的问卷反馈

以下为实验组织者汇总。逐次与汇总的行为复核见 [V06 正式运行分析](../数据包/V06/README.md)。

| 问卷或设计观察 | 运行数据中的对应证据 | 下一轮验证 |
|---|---|---|
| 120 秒影片唤醒仍低，到 2-back 后几乎不维持 | 唤醒度平均上升有限、消极效价不一致，影片后至 2-back 开始相隔 96–163 秒。没有 2-back 后自评 | 先筛清晰且高唤醒的候选片，再实验比较升 N 后短维持片与无维持片 |
| 2-back 的 ABB 容易辨认。对词有印象、知道大致距离也可能是有信息的记忆表现 | 96 个 ABB 的正确键都是 F，但整体正确率和 RT 与另一方向诱饵接近。首次出现词仍更快、更准 | 将近邻方向误报、普通熟悉非匹配和首次出现非匹配分开，验证邻接线索是否改变任务测量 |
| 热身后仍在熟练，后续感觉更集中；时长和单调也可能带来疲劳 | 固定 1-back 看组序，后两组总体更准；固定 1–3-back 看同一区块，四次后半都降，最后组的区块内三降一平。没有直接注意/疲劳评分或足够顺序平衡 | 保留并量化热身表现，平衡顺序，记录注意/疲劳，验证缩短或固定 N 后的效果 |
| 情绪激发受环境影响，建议保持安静，消极片可考虑暗光 | 原运行没有独立操控环境的资料 | 主比较统一安静度、照度和视听参数。如果评估暗光，另做平衡照度的对照 |
