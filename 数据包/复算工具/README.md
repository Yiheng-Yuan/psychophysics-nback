# 复算与绘图

脚本读取各版本 `运行包/` 下的 ZIP，不改动归档数据。可从仓库根目录运行下列命令。

| 工具 | 作用 | 输出 |
|---|---|---|
| [复算.py](复算.py) | 检查运行清单、计分、区块和等级，并复算准确率、反应时、d′ 等 | JSON 写到标准输出 |
| [绘图.py](绘图.py) | 生成各版的情绪条件汇总图 | 各版 `图表/Vxx-情绪表现.png` |
| [逐次绘图与分析.py](逐次绘图与分析.py) | 生成每次运行的统计表和轨迹图 | 各版 `逐次分析.md` 和 `图表/Vxx-Rxx.png` |

[V06反馈复核.py](V06反馈复核.py)复算正式批次的 ABB、组序、区块前后半和片尾至测试的时差。[V06反馈图.py](V06反馈图.py)写入 `数据包/V06/图表/V06-反馈复核.png`。[V06配对图.py](V06配对图.py)写入同目录的 `V06-逐次干扰差值.png` 和 `V06-自评原始分.png`。通用绘图和逐次分析可用 `--version V06` 只更新该版本。

复算只用 Python 标准库。绘图需要 Matplotlib 和中文字体，找不到字体时可用 `--font` 指定字体文件。

```sh
python3 数据包/复算工具/复算.py
python3 数据包/复算工具/绘图.py
python3 数据包/复算工具/逐次绘图与分析.py
python3 数据包/复算工具/V06反馈复核.py
python3 数据包/复算工具/V06反馈图.py
```

## 核对归档和复现 V06 新增图表

从仓库根目录运行：

```sh
python3 数据包/复算工具/归档维护.py
python3 数据包/复算工具/V06反馈复核.py --markdown > 数据包/V06/逐次配对.md
python3 数据包/复算工具/V06配对图.py
```

归档维护工具默认只检查。它从运行清单复算 CSV 索引，核对 40 份公开代码及数据 ZIP 的校验值，并用已归档的 V06-R01 回归检查计分、晋级、题型配额、漏答、正确反应时和 d′。只有在确认归档增删或替换有记录后，才使用 `--write` 更新索引和校验和。发布页的可下载情绪素材有[独立校验文件](https://github.com/Yiheng-Yuan/psychophysics-nback/releases/tag/emotion-stimuli-v1)。V06 影片的文件校验值见[情绪素材与来源](../../文档/情绪素材.md)。

V06 配对图脚本可用 `--font` 指定中文字体。新增图表已在 Python 3.12、Matplotlib 3.11.2 下生成。通用复算直接读取各版日志的有效 J/F 作答。V06 程序设 3 秒作答窗。反应时中位数只取有效、正确、有反应时记录的作答，脚本未额外执行 200 毫秒下限或重新按作答窗口过滤。共同 1–3-back 的现有记录中没有低于 200 毫秒的反应时。
