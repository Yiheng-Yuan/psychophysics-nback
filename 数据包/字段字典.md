# 运行索引与数据字段

[运行索引 CSV](runs.csv)由[归档维护工具](复算工具/归档维护.py)从公开 ZIP 生成。每行对应一个运行包或故障摘要。使用 UTF-8，路径相对于仓库根目录。

| 字段 | 含义 |
| --- | --- |
| `run_id` | 公开运行编号，如 V06-R01。同一人可能参加多次运行。 |
| `version` | 归档版本，如 V06。 |
| `archive`、`code_archive` | 运行 ZIP 与对应版本代码 ZIP。V06 故障摘要对应版本系列，所链接的代码是末帧修复后的发行包。 |
| `status` | 运行清单的完成状态。没有清单的故障记录标为“故障摘要”。 |
| `include_complete_run_summary` | 1 表示清单中已有三个情绪组的汇总，纳入完整运行汇总。0 表示只作为部分运行、空运行或故障记录。 |
| `reason` | 未纳入完整运行汇总的原因。已纳入时为空。 |
| `recorded_trials`、`scored_trials`、`correct_trials` | 全部记录、计分试次及正确试次数。仅有故障摘要时为空。 |
| `completed_blocks` | 有区块汇总记录的区块数。 |
| `emotion_order` | 运行清单记录的情绪顺序，用竖线分隔。部分运行可能只执行了其中一部分。 |

V01 的早期图表另展示唯一有汇总的区块。它仍属于部分运行。V06 中的 pilot 已于发布前排除，未进入公开 ZIP 或索引。索引只覆盖可下载的公开记录。

## 运行 ZIP 的主要字段

各版字段随程序变化。缺失字段保留为空，空值、0 和不适用分别理解。

| 文件 / 字段 | 含义 |
| --- | --- |
| `manifest.json` | 公开运行编号、版本标识、配置、状态、情绪顺序及试次数。 |
| `trials.csv` · `participant`、`session` | 去标识化运行编号及本次运行内的任务组。公开的 `participant` 字段不可用于跨运行确认同一被试。 |
| `trials.csv` · `emotion`、`n`、`distractor_level` | 影片或诱导条件（positive / neutral / negative）、N-back 等级、是否有上下干扰词（with / without）。 |
| `trials.csv` · `repetition`、`trial_index`、`scored` | 同条件区块的重复号、区块内从 1 起计的位置、是否纳入计分。区块开头的 N 个启动词不计分。 |
| `trials.csv` · `word`、`is_match`、`is_lure` | 中央目标词、是否与前第 N 个词相同、是否为近邻位置诱饵。 |
| `trials.csv` · `lure_direction`、`seen_before` | 适用的版本记录诱饵方向（lure_minus / lure_plus 分别对应 N−1 / N+1）与该词此前是否在本区块出现。1-back 的 N−1 方向不适用。 |
| `trials.csv` · `correct_key`、`response_key`、`correct` | 正确键、实际键、作答是否正确。J 为匹配，F 为非匹配。无有效 J/F 作答记入漏答。 |
| `trials.csv` · `rt_seconds` | 反应时，单位为秒。报告换算为毫秒。 |
| `blocks.csv`、`level_results.csv`、`summary.csv` | 区块汇总、等级通过判断和各情绪组汇总。 |
| `emotion_ratings.csv` | 记录了自评的版本中，片前片后效价与唤醒度各为 1–9 分。 |
| `stage_log.csv`、`video_log.csv` | 可用的流程阶段和播放状态。V06 公开阶段日志保留从运行开始计算的相对秒数。 |

正确率的分母为全部计分试次，含漏答。正确反应时仅使用有效且正确的 J/F 反应。命中、误报及辨别力 d′ 的分母使用有效 J/F 作答。详见[复算入口](复算工具/README.md)。
