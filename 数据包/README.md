## 如何查找

- 想看某一版整体结果，进入该版本的 `README.md`。其中有汇总图、配对比较和改动依据。
- 想看某一次，打开该版的 `逐次分析.md`，用运行编号定位表格和图。原始 ZIP 在同目录的 `运行包/`。
- 想看改版前后变化，查看 [跨版本分析](跨版本分析.md)，其中区分运行证据、组织者转述与待验证解释。

例如 [V05-R01 的逐次分析](V05/逐次分析.md#v05-r01)对应 [V05-R01.zip](V05/运行包/V05-R01.zip)，程序版本对应 [V05.zip](../代码包/V05.zip)。

X90、X120 和 W01 可在 [代码包索引](../代码包/README.md)找到。X90 与 X120 没有已归档的被试运行；W01 独立热身只显示成绩，未生成运行数据。
