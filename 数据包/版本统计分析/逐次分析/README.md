# 逐次运行分析

同一版本下，每个公开运行编号单独分析。不同编号可能属于同一名被试，去标识化归档没有可用于可靠合并的身份信息。

| 版本 | 逐次分析 | 覆盖 |
|---|---|---|
| V01 | [早期 Builder](V01.md) | 1 次部分运行 |
| V02 | [同字号同颜色、80%](V02.md) | 2 次完成、4 次部分 |
| V03 | [十词与 8／8／8 配额](V03.md) | 2 次完成、3 次部分 |
| V04 | [短版、85%](V04.md) | 2 次完成、3 次部分、1 次无计分 |
| V05 | [配对词序 v0.1](V05.md) | 5 次完成 |
| V06 | [120 秒单次影片](V06.md) | 1 次完成、1 次部分、1 份闪退摘要 |

每次有计分记录的运行都附有图表，按情绪、N 和有无干扰展示准确率及正确反应时。表格另列漏答、命中、虚报、校正 d′、各试次类型，以及两种干扰条件都完成时的同情绪同 N 差值。空心点显示未完成计划区块的条件，缺失条件不补值。部分运行用于诊断流程，空记录与闪退摘要无法计算表现指标。V06 只含已归档的先行数据。
