# 情绪诱导、视觉干扰与词语 N-back

心理物理学综合设计实验。**上传与归档维护：Yiheng Yuan。**

[数据与分析](数据包/README.md) · [历版实验代码](代码包/README.md) · [实验设计与文档](文档/README.md)

## 1. 研究问题

在词语工作记忆任务中，**不同情绪诱导条件下的 N-back 表现是否不同？无关词的视觉干扰是否影响表现？干扰的影响是否随情绪条件而变化？**

本实验用图片、音频或影片呈现不同情绪情境，用上下无关词增加视觉干扰，再用词语 N-back 观察工作记忆表现。被试需不断更新刚见过的词，并判断当前词是否与前第 N 个词相同。我们比较各条件的正确率和反应时，也通过诱饵题检查被试能否仅凭熟悉度作答。

## 2. 研究方法

### 实验如何迭代

早期先用图片诱导情绪，之后加入音频，并把上下干扰词改成与中央词同样的外观。长版每个等级要做四个区块，部分被试反馈耗时长、难度提高后想尽快结束，因此短版改为两个。被试也提到有时凭词语印象判断，后续版本据此调整了诱饵和词序。由于声画诱导的主观感受较弱，最后一版改用 120 秒影片，并在播放前后加入效价和唤醒度自评。各版的具体改动及依据见 [设计与版本](文档/设计与版本.md)。

### 最后一版的自变量、因变量和控制

| 项目 | 操作与记录 |
|---|---|
| 被试内自变量一 | 三种情绪诱导条件。积极、中性、消极各播放一段 120 秒影片，使用同一套播放和评分流程。 |
| 被试内自变量二 | 有无视觉干扰。有干扰时上、中、下三个词同色、同大小、同字重。无干扰时只显示同样样式的中央词。两种条件都只比较中央词。 |
| 任务难度 | N 为自适应等级。每种情绪从 1-back 开始，每级有干扰和无干扰各一区块；任一条件答对至少 21/24 可升一级，最高 6-back。比较干扰效应时优先使用共同达到的同一 N。 |
| 行为因变量 | 正确率、匹配命中率、非匹配虚报率、辨别力 d′（区分匹配和非匹配的能力）、正确反应时及最高通过 N。最高 N 是由升级门槛决定的辅助指标。 |
| 情绪操纵检查 | 每段视频播放前后各评一次效价与唤醒度，均为 1–9 分。效价指感受有多愉快，唤醒度指感受有多强烈或激动。 |
| 顺序与时序控制 | 程序可按编号分配六种情绪顺序之一，同一等级平衡有无干扰先后，并使用结构相近的配对词序。词最多显示 1 秒，反应截止 3 秒，即时反馈 0.5 秒，十字 0.7 秒。实际试次历时随反应速度变化。 |

正式流程为 **独立 1–3-back 热身 → 每种情绪的片前自评 → 120 秒影片 → 片后自评 → 该情绪的 N-back**。三种情绪依次完成。热身每级 8 道计分题，正式任务每区块先显示 N 个启动词，再呈现 24 个计分词。当前词与前第 N 个中央词相同按 **J**，否则按 **F**。升 N 时没有补充影片或情绪自评。影片暂用老师合集的竹林、憨豆野餐和夜间惊险片段，对应中性、积极和消极候选，尚未取得截段常模。

### 匹配、诱饵与其他非匹配

分类只比较**中央词序列**。以 2-back 为例，假设当前词出现前，最近三个中央词按时间先后是 **苹果 → 书包 → 椅子**。所以前 1 步是椅子，前 2 步是书包，前 3 步是苹果。

| 试次类型 | 定义 | 上述 2-back 序列下的当前词 | 正确键 |
|---|---|---|---|
| 匹配（Match） | 当前中央词等于往前第 N 个中央词。 | **书包**，与前 2 步相同。 | **J** |
| 诱饵（Lure） | 当前中央词与前 N 步不同，但与前 N−1 或 N+1 步的中央词相同。1-back 只用 N+1 方向，因为 N−1 为当前这一位置。 | **椅子**或**苹果**，分别与前 1 步、前 3 步相同。 | **F** |
| 其他非匹配（Other nonmatch） | 当前中央词与前 N 步和适用的相邻位置都不同。当前词可以首次出现，也可以在更早的位置出现过。 | **水杯**。如果水杯前 4 步出现过，仍属于其他非匹配。 | **F** |

程序先判断匹配。当前词如果同时符合前 N 步和邻近位置，仍归为匹配。如果它只同时命中两个诱饵位置，生成器会丢弃该候选，以保证每个诱饵只有一个方向。各比较位置须已有中央词可供比较。每组前 N 个启动词用于建立序列，从第 N+1 个词开始计分。屏幕上下的干扰词不进入中央词序列。

### 词序更新如何实现

**关键改动是先排定同一个词出现的位置，再把词填进去。** 这样可以安排每类计分题的数量，并控制一个词隔多久再次出现。

1. **先针对熟悉度线索增加诱饵。** 有被试口述凭主观印象作答，有印象按 J、没有印象按 F。但“曾经见过”与“恰好出现在 N 步前”是两件事。例如在 2-back 中，当前词只和上一个词或前三个词相同，就是熟悉却必须按 F 的诱饵。
2. **把三类试次写进生成约束。** 每区块 8 个匹配、8 个诱饵、8 个其他非匹配。2–6-back 的诱饵分别来自 N−1、N+1，各四个。先判断真正的 N 匹配。如果不匹配但同时命中两种相邻位置，该候选被丢弃，避免同一试次被重复归类。1-back 只有 N+1 方向，继续沿用旧版生成器并对候选排序。
3. **抑制少数词循环和长串同类反应。** 2–6-back 用束搜索，从 N 个不同的启动词符号出发，每步尝试已有符号或引入一个新符号，通常保留约 200 条候选。超出配额或词频上限、连续六个位置只有两种词等候选直接淘汰。对词频集中、很长的连续 F 和局部重复加入软惩罚。2-back 在多个可行结果中优先选最长 F 串较短的结果，没有用固定长度的 F 串强制预测下一个 J。
4. **限制实际新词数。** 每区块抽 10 个词作为候选池，最终替换到符号骨架中的实际词数随 N 变化。已实现的每级目标如下。由于 1-back 保留旧逻辑，有 7 个计分位置可以首次见到词，这一捷径仍较明显。

| N | 实际使用的词数 | 计分阶段首次出现词数 | 匹配／诱饵／其他非匹配 |
|---|---:|---:|---|
| 1 | 8 | 7 | 8／8／8 |
| 2 | 5 | 3 | 8／8／8 |
| 3 | 6 | 3 | 8／8／8 |
| 4 | 7 | 3 | 8／8／8 |
| 5 | 7 | 2 | 8／8／8 |
| 6 | 8 | 2 | 8／8／8 |

下面是正式生成器 category_for 的核心，用当前序列长度 i 表示即将追加的位置。前 N 个启动词先单独生成，所以进入此函数时 i ≥ N。

```python
i = len(seq)
if word == seq[i-n]:
    return 'match'
minus = n > 1 and i >= n-1 and word == seq[i-(n-1)]
plus = i >= n+1 and word == seq[i-(n+1)]
if minus and plus:
    return None
if minus:
    return 'lure_minus'
if plus:
    return 'lure_plus'
return 'other_nonmatch'
```

**独立生成两批候选序列，每批三条，比较九种跨批配对。** 使用前 12 题的匹配数、两方向诱饵数、首次出现词数、最高单词频次、最长 F 串、已出现普通非匹配距最近出现的平均间隔作为配对特征。选加权距离最小的一对，再随机把 A/B 分给有无干扰。配对比较的是整体特征，程序没有逐题对齐两条序列。配对减少词序难度不一致的风险，上下词是否影响成绩仍需要行为数据判断。

```python
info1 = [block_signature(block) for block in one]
info2 = [block_signature(block) for block in two]
distance, i, j = min(
    (pair_distance(a, b), i, j)
    for i, a in enumerate(info1)
    for j, b in enumerate(info2)
)
```

## 3. 数据分析与目前发现

**词序更新达到了预定的配额。** V05 的五次完整运行共 80 个区块，每区块都是 8 个匹配、8 个诱饵和 8 个普通非匹配。在已观察到的 2–4-back 中，两种距离的诱饵各 4 个。三次预测试中，首次出现的普通非匹配比熟悉的普通非匹配答得更快，三次分别答对 64/66、66/66 和 78/78。这个现象与被试所说的「凭词语印象作答」相符。 [跨版本数据](数据包/跨版本分析.md)

**最后一版的情绪和干扰差异随人、随等级变化。** 四次运行均完成了三种情绪下的 1–3-back。比较共同的 1–3-back，积极、中性和消极条件的正确率分别为 **91.7%、92.0%、89.2%**，个体结果的高低顺序并不一致。在同一人、同一情绪和同一 N 下，有干扰时 36 个配对有 23 个反应较慢、13 个较快。正确率则有 13 个较高、14 个较低、9 个相同。 [V06 汇总与逐次图表](数据包/V06/README.md)

**数据下载。** [逐次 ZIP 索引](数据包/运行索引.md)提供 27 次去标识化运行及 1 次运行故障摘要。运行包按版本整理，包含可取得的逐试次作答、反应时、区块统计、自评和配置。独立热身的成绩当场显示。

## 4. 后续改进

1. 对词序的思考：词序是否真的重要？只要控制其在不同情绪下的相同统一的词序产生规律，是否就对实验结果不产生影响？词语印象、词语距离印象可以算作进入工作记忆但是并不准确，记忆程度优于完全无印象。类似失误多少等情况都可作为相关参考指标。

2. **保留 1–3-back 热身，记录被试何时熟悉任务。** 有被试反馈，热身后仍会逐渐熟悉任务，并感觉注意更集中。最后一版固定比较 1-back，第一至第三个情绪组的正确数为 **172/192 → 185/192 → 183/192**，第二组的正确率最高，正确反应时也最短。下一轮可记录热身成绩和完成热身所需时间，并平衡情绪顺序，便于区分熟练程度和影片条件的影响。注意是否更集中，可以另外收集组末自评。 [练习趋势复核](文档/预测试数据.md#同一-n-的练习趋势复查)

3. **缩短单次实验，关注末段的作答负担。** 被试反馈任务较单调，能接受的实验时长因人而异。最后一版的四次完整运行约 **27–41 分钟**。在最后一个情绪组内，比较相同等级区块的前 12 题和后 12 题，有三次运行的后半正确率下降，一次持平。下降最大的一次从 **67/72 降到 59/72**。下一轮可缩短流程，在同类题目上比较前后表现，并用组末疲劳评分了解下降是否伴随主观疲劳。 [逐次观察](数据包/V06/逐次观察.md)

4. **保持环境安静，预试情境照明。** 统一播放音量、屏幕亮度和室内照度，减少周围环境对看片和作答的影响。可在独立预试中，用同一段消极影片对比标准光和暗光，记录情绪体验及文字可读性，再决定是否引入情境照明。

5. **先测个人最高 N，再固定难度比较情绪条件。** 正式实验前，在无额外情绪诱导的基线预实验中测定个人最高通过 N。正式实验中每次诱导后只做这个 N，保留有干扰和无干扰两个区块，在同一难度下比较正确率、错误类型、正确反应时和 d′。先用预测试确认最高 N 的测量是否稳定，并检查该等级下被试能否持续有效作答。
