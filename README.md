# 情绪诱导、视觉干扰与词语 N-back

心理物理学综合设计实验。**上传与归档维护：Yiheng Yuan。**

[数据与分析](数据包/README.md) · [历版实验代码](代码包/README.md) · [实验设计与文档](文档/README.md)

## 1. 研究问题

在词语工作记忆任务中，**不同情绪诱导条件下的 N-back 表现是否不同？无关词的视觉干扰是否影响表现？干扰的影响是否随情绪条件而变化？**

课程要求探索情绪、记忆和注意之间的关系。本实验用影片改变情绪情境，用上下无关词增加选择性注意负荷，用词语 N-back 测量维持和更新任务信息时的行为表现。预期无关词可能增加误报或延长反应时，情绪是否改变这种干扰效应是探索性问题。预测试同时用于检查被试能否用词语熟悉度绕开任务要求。

## 2. 研究方法

### 自变量、因变量和控制

| 项目 | 操作与记录 |
|---|---|
| 被试内自变量一 | 三种情绪诱导条件。积极、中性、消极各播放一段 120 秒影片，使用同一套播放和评分流程。 |
| 被试内自变量二 | 有无视觉干扰。有干扰时上、中、下三个词同色、同大小、同字重。无干扰时只显示同样样式的中央词。两种条件都只比较中央词。 |
| 任务难度 | N 为自适应等级。每种情绪从 1-back 开始，每级有干扰和无干扰各一区块；任一条件答对至少 21/24 可升一级，最高 6-back。比较干扰效应时优先使用共同达到的同一 N。 |
| 行为因变量 | 正确率、匹配命中率、非匹配虚报率、辨别力 d′、正确反应时及最高通过 N。最高 N 是由升级门槛决定的辅助指标。 |
| 情绪操纵检查 | 每段视频播放前后各评一次效价与唤醒度，均为 1–9 分。看同一人看片前后变化，以及正负影片的唤醒度是否接近。 |
| 顺序与时序控制 | 程序可按编号分配六种情绪顺序之一，同一等级平衡有无干扰先后，并使用结构相近的配对词序。词最多显示 1 秒，反应截止 3 秒，即时反馈 0.5 秒，十字 0.7 秒。实际试次历时随反应速度变化。 |

正式流程为 **独立 1–3-back 热身 → 每种情绪的片前自评 → 120 秒影片 → 片后自评 → 该情绪的 N-back**。三种情绪依次完成。热身每级 8 道计分题，正式任务每区块先显示 N 个启动词，再呈现 24 个计分词。当前词与前第 N 个中央词相同按 **J**，否则按 **F**。升 N 时没有补充影片或情绪自评。影片暂用老师合集的竹林、憨豆野餐和夜间惊险片段，对应中性、积极和消极候选，尚未取得截段常模。

### 匹配、诱饵与其他非匹配

分类只比较**中央词序列**。以 2-back 为例，假设当前词出现前，最近三个中央词按时间先后是 **苹果 → 书包 → 椅子**。所以前 1 步是椅子，前 2 步是书包，前 3 步是苹果。

| 试次类型 | 定义 | 上述 2-back 序列下的当前词 | 正确键 |
|---|---|---|---|
| 匹配（Match） | 当前中央词等于往前第 N 个中央词。 | **书包**，与前 2 步相同。 | **J** |
| 诱饵（Lure） | 当前中央词与前 N 步不同，但与前 N−1 或 N+1 步的中央词相同。1-back 只用 N+1 方向，因为 N−1 为当前这一位置。 | **椅子**或**苹果**，分别与前 1 步、前 3 步相同。 | **F** |
| 其他非匹配（Other nonmatch） | 当前中央词与前 N 步和适用的相邻位置都不同。当前词可以首次出现，也可以在更早的位置出现过。 | **水杯**。如果水杯前 4 步出现过，仍属于其他非匹配。 | **F** |

程序先判断匹配。当前词如果同时符合前 N 步和邻近位置，仍归为匹配。如果它只同时命中两个诱饵位置，生成器会丢弃该候选，以保证每个诱饵只有一个方向。各比较位置须已有中央词可供比较。每组前 N 个启动词只用于建立序列，不计入上述三类；屏幕上下的干扰词也不进入序列。

### 词序更新如何实现

**关键改动是先生成满足约束的重复位置结构，再给这个结构填入汉语词。** 这样可以直接控制每次出现是正确位置匹配、近邻位置诱饵，还是其他非匹配，而不是随机抽取词后碰运气凑够各类试次。

1. **先解决熟悉度捷径。** 有被试口述凭主观印象作答，有印象按 J、没有印象按 F。但“曾经见过”与“恰好出现在 N 步前”是两件事。例如在 2-back 中，当前词只和上一个词或前三个词相同，就是熟悉却必须按 F 的诱饵。
2. **把三类试次写进生成约束。** 每区块 8 个匹配、8 个诱饵、8 个其他非匹配。2–6-back 的诱饵分别来自 N−1、N+1，各四个。先判断真正的 N 匹配。如果不匹配但同时命中两种相邻位置，该候选被丢弃，避免同一试次被重复归类。1-back 只有 N+1 方向，继续沿用旧版生成器并对候选排序。
3. **抑制少数词循环和长串同类反应。** 2–6-back 用束搜索，从 N 个不同的启动词符号出发，每步尝试已有符号或引入一个新符号，通常保留约 200 条候选。超出配额或词频上限、连续六个位置只有两种词等候选直接淘汰。对词频集中、很长的连续 F 和局部重复加入软惩罚。2-back 在多个可行结果中优先选最长 F 串较短的结果，没有用固定长度的 F 串强制预测下一个 J。
4. **限制实际新词数。** 每区块抽 10 个词作为候选池，最终替换到符号骨架中的实际词数随 N 变化。已实现的每级目标如下。由于 1-back 保留旧逻辑，有 7 个计分位置可以首次见到词，这一捷径仍较明显。

| N | 实际使用的词数 | 计分阶段首次出现词数 | 匹配／诱饵／其他非匹配 |
|---|---:|---:|---|
| 1 | 8 | 7 | 8／8／8 |
| 2 | 5 | 3 | 8／8／8 |
| 3 | 6 | 3 | 8／8／8 |
| 4 | 7 | 3 | 8／8／8 |
| 5 | 7 | 2 | 8／8／8 |
| 6 | 8 | 2 | 8／8／8 |

下面是正式生成器 category_for 的核心，用当前序列长度 i 表示即将追加的位置。前 N 个启动词先单独生成，所以进入此函数时 i ≥ N。

```python
i = len(seq)
if word == seq[i-n]:
    return 'match'
minus = n > 1 and i >= n-1 and word == seq[i-(n-1)]
plus = i >= n+1 and word == seq[i-(n+1)]
if minus and plus:
    return None
if minus:
    return 'lure_minus'
if plus:
    return 'lure_plus'
return 'other_nonmatch'
```

**独立生成两批候选序列，每批三条，比较九种跨批配对。** 使用前 12 题的匹配数、两方向诱饵数、首次出现词数、最高单词频次、最长 F 串、已出现普通非匹配距最近出现的平均间隔作为配对特征。选加权距离最小的一对，再随机把 A/B 分给有无干扰。配对比较的是整体特征，程序没有逐题对齐两条序列。配对减少词序难度不一致的风险，上下词是否影响成绩仍需要行为数据判断。

```python
info1 = [block_signature(block) for block in one]
info2 = [block_signature(block) for block in two]
distance, i, j = min(
    (pair_distance(a, b), i, j)
    for i, a in enumerate(info1)
    for j, b in enumerate(info2)
)
```

## 3. 数据分析与目前发现

| 观察 | 数据和解释 |
|---|---|
| **词序约束在现有作答记录中确实执行** | 复算 v0.1 的五次完成运行，共 80 个区块。1、2、3、4-back 分别有 30、26、20、4 个区块，每区块的三类各 8 次。2–4-back 的两方向诱饵都是每区块各 4 次。计分词首次出现数在 1-back 为每区块 7 个，2–4-back 为每区块 3 个。该组数据未到 5–6-back。 |
| **熟悉度仍可辅助作答** | 三份会话附件中，首次出现的普通非匹配分别答对 64/66、66/66 和 78/78，三份记录中的正确反应也都比熟悉的普通非匹配更快。结果与部分被试口述一致。行为数据本身无法区分某一次反应采用了什么策略。 |
| **干扰效应和情绪差异尚不稳定** | 三份附件的无／有干扰正确数分别为 126/168 与 146/168、140/168 与 140/168、178/216 与 179/216。三份记录的中性都在第二位，同一版本最高 N 会随情绪和个体变化。异 N、异版本总体准确率只作描述。 |
| **出现过练习带来的准确率上升** | 根据先前分析，实验组织者在不同情绪顺序中都注意到熟悉任务后准确率上升，因此加入正式实验前的热身。本次限定在 1-back、按第 1／2／3 个情绪组复核。短版初期两次完成运行合计为 84/96 → 92/96 → 91/96，v0.1 五次合计为 219/240 → 215/240 → 227/240。后者第三组较第一组高，但存在下降个例和第二组回落。位置同时随情绪和时间变化，现有数据无法估计纯练习效应。 |
| **后段表现取决于比较尺度** | V06 的四次完成运行中，固定 1-back 看情绪组序，后两组的汇总准确率高于首组。比较同一区块的前后半，后半正确率反而更低。两种结果可以同时出现。 [V06 正式批次分析](数据包/V06/README.md) |

## 4. 后续改进

以下是贯穿整个实验的反思。最后一次实验特有的 **120 秒影片维持反馈**和 **2-back 的 ABB 线索**，见 [V06 正式运行分析](数据包/V06/README.md)。

1. **词序既关系到条件是否公平，也关系到任务测到了什么。** 各情绪使用相同的生成规则，可以统一匹配、诱饵和普通非匹配的配额与重复间隔要求。不同区块实际抽到的词、排列难度和被试采用的策略仍可能不同。即使各情绪的词序分布相近，被试也可能在不同阶段更多依赖熟悉度或距离印象，因此不能仅凭生成规则一致，就认为词序对结果没有影响。后续应继续统一规则、随机分配配对序列，并核对实际的词频、重复间隔和诱饵分布。

   对某个词有印象，或记得它大概出现在多远之前，可以视为保留了部分信息的候选表现。它可能反映不精确的工作记忆，也可能来自较粗略的熟悉判断，单凭一次按键无法区分。正式正确率仍按精确 N 步匹配计算。另按**目标漏报、近邻诱饵误报、其他熟悉非匹配的误报、首次出现词的错误及正确反应时**分别报告，检查错在记不住词，还是记住了词却判断错了位置。 [分版本词序复核](数据包/跨版本分析.md)

2. **保留 1–3-back 热身，并量化热身后的继续熟练。** 在正式诱导前用热身练习 J/F、启动词和中央词比较。问卷显示，在热身之后仍有被试感觉越来越熟悉、注意更集中。固定 1-back 后，V04 的三组正确数是 **84/96 → 92/96 → 91/96**，V05 是 **219/240 → 215/240 → 227/240**。V06 是 **172/192 → 185/192 → 183/192**，正确反应时中位数是 **595 → 579 → 598 ms**。这些结果支持热身后仍可能有熟练变化，但准确率提升与反应加快并不总是同步。日志也没有直接测量注意力，现有顺序覆盖无法验证“注意更集中与情绪顺序无关”。下一轮可保存热身表现，设定规则掌握标准，均衡情绪顺序，并在同一 N 下分别跟踪准确率、失误和反应时。 [位置复核](文档/预测试数据.md#同一-n-的练习趋势复查)

3. **缩短单次实验，并用同难度的前后对照追踪疲劳。** 被试反馈任务单调、可接受的时长不一样，后半有时明显掉分。V06 四次完成运行约 **27–41 分钟**。固定 1–3-back 比较同一区块前后半，四次后半正确率都下降。只看最后一个情绪组内的区块前后半，则为 **三次下降、一次持平**，其中一次从 **67/72 降至 59/72**。相比之下，第三组的固定 1-back 没有一次低于首组。不同时间尺度上的结果可以同时出现。区块后半的题型比例也有变化，且没有同步疲劳评分，因此不能把后半下降仅归因于疲劳。后续应记录实际用时、漏答、组末疲劳与注意自评，并在同一 N、同一试次类型内比较前后表现。 [逐次疲劳与熟练观察](数据包/V06/逐次观察.md)

4. **统一实验环境，单独检验情境照明。** 情绪诱导与注意任务都需要安静环境。正式比较时保持房间背景噪声、播放音量、屏幕亮度和室内照度尽量一致。暗光能否增强消极情境可以单独预测试，例如在同一影片下对比标准光与暗光，并同时看情绪自评、文字可读性和 N-back 表现。只在消极条件调暗灯光会使照明与影片情绪同时改变。 [反馈与改进](文档/反馈与改进.md)

5. **先测个人最高 N，再固定难度比较情绪条件。** 正式实验前，在无额外情绪诱导的基线预实验中，按预先规定的升级标准测定每名被试的最高通过 N。正式实验中，每次情绪诱导后只做该被试预先测得的 N，保留有干扰和无干扰两个区块。这样可以在同一被试、同一等级下比较命中率、虚报率、校正 d′、正确反应时和正确率，也能缩短诱导后到目标等级的时间。先检查最高 N 的测量是否稳定及作答是否充足，并把影片前后效价与唤醒度作为独立的操纵检查。
